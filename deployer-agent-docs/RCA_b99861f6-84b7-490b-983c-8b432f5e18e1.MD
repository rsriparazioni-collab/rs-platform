All other October days reconcile to 0. So ~9 flagged days, in two structural buckets:

**Bucket A — AdE recorded 0 / register closure while the store logged sales**
(10-05, 10-12, 10-14, 10-21, 10-28). The AdE row exists with `totale=0` (imponibile/imposta
both 0) on dates where the store's manual corrispettivi show merce/riparazioni. This is a
genuine source gap — either the register was inactive/closed those days, or the receipts went
through a register/matricola not reported to AdE under 1BENI099492. The new code cannot
"remove" this — there is no double-closure, no apici, no totale-vs-ammontare issue to fix; the
AdE source simply reports nothing for those days.

**Bucket B — difference equals art74** (10-15, 10-17, 10-26; partially 10-29). The AdE totale
matches `scontrini` (which INCLUDES art74), while the comparison basis is `riparazioni+merce`
(which EXCLUDES art74). So the on-screen difference equals the art74 amount by construction.
This is a direct consequence of the "comparison = riparazioni+merce only" design, not a stale
build.
